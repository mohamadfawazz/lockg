# LOCKG website

Live at https://lockg.xmf.app (Cloudflare Pages project `lockg`).

- `site/index.html` LOCKG ONE 3D product page
- `site/configure/index.html` room page
- `site/shell.js`, `site/shell.css` app bar, sheets, EN/AR, order form, chat

Every push to `main` deploys automatically (needs repo secret `CLOUDFLARE_API_TOKEN`).
